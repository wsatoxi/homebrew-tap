# wsatoxi/homebrew-tap

Homebrew tap for apps by [@wsatoxi](https://github.com/wsatoxi).

## Install

```bash
brew install wsatoxi/tap/display-switcher
```

| Cask | Description |
|---|---|
| [`display-switcher`](Casks/display-switcher.rb) | [Display Switcher](https://github.com/wsatoxi/DisplaySwitcher) — switch macOS display modes with one shortcut |

> [!NOTE]
> Display Switcher is not notarized by Apple yet. The first time you open it, go to
> **System Settings › Privacy & Security** and click **Open Anyway**.
